# 排序模型训练指南

一部电影展示给用户，就是一次曝光。在下面的例子里，用户点击了其中一部，另一部展示后没有点击。假设我们用 DeepFM 预测这两次曝光的点击概率，该怎样判断预测好不好？

- **AUC 看次序。** 如果给点击和未点击的电影分别打 0.6、0.4，点击的电影排在前面。把分数改成 0.9、0.1，次序没变，这对样本对 AUC 的贡献也没变。
- **LogLoss 还看概率。** 两组预测的平均 LogLoss 分别约为 0.511 和 0.105。第二组给真实点击更高的概率，所以损失更小。反过来，如果模型很有把握却猜错了，损失也会更大。

`CTRTrainer` 在验证 AUC 严格提高时保存权重。批内采样会改变训练样本中正负配对的比例，评估仍使用真实曝光标签。可用[快速入门](/zh/guide/quick_start)跑出第一个 AUC，再用[排序教程](/zh/tutorials/ctr)切换模型。
